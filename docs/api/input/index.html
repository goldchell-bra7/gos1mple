input Package

The input package centralizes console user input handling. It replaces repetitive standard library scanning code with clean, intuitive one-line helpers supporting integers, floats, strings, and booleans.

import "github.com/goldchell-bra7/gos1mple/input"
📋 Functions Reference
Function Return Type Prompt Behavior
ReadInt(prompt) int Inline prompt (same line)
ReadIntln(prompt) int Prompt followed by newline
ReadFloat(prompt) float64 Inline prompt (same line)
ReadFloatln(prompt) float64 Prompt followed by newline
ReadString(prompt) string Inline prompt (single word)
ReadStringln(prompt) string Prompt followed by newline
ReadBool(prompt) bool Inline prompt (true/false)
ReadBoolln(prompt) bool Prompt followed by newline
🔍 Detailed Documentation

ReadInt

Displays a prompt string without a trailing newline, reads a single integer from standard input, and returns the parsed value. Centralizes integer handling to eliminate boilerplate across projects.

signature 
func ReadInt(prompt string) int
example.go 
age := input.ReadInt("Enter your age: ")
fmt.Printf("User age is: %d\n", age)

ReadIntln

Displays a prompt followed by a newline, reads an integer from standard input, and returns the value. Printing the prompt on its own line improves visual clarity in multi-line console dialogs.

signature 
func ReadIntln(prompt string) int
example.go 
count := input.ReadIntln("How many items would you like to process?")
fmt.Printf("Processing %d items...\n", count)

ReadFloat

Displays a prompt on the current line, reads a 64-bit floating-point number from standard input, and returns the parsed float. Ideal for calculations requiring decimal precision (e.g. calculators, currencies, measurements).

signature 
func ReadFloat(prompt string) float64
example.go 
price := input.ReadFloat("Enter item price ($): ")
fmt.Printf("Total with tax: $%.2f\n", price*1.20)

ReadFloatln

Prints the prompt on its own line followed by a newline, then reads a float64 from standard input. Cleaner layout for longer prompts or instructions.

signature 
func ReadFloatln(prompt string) float64
example.go 
rate := input.ReadFloatln("Please enter the interest rate percentage:")
fmt.Printf("Selected rate: %.3f%%\n", rate)

ReadString

Displays an inline prompt and reads a single whitespace-delimited word from standard input. Suitable for usernames, single commands, or identifiers.

signature 
func ReadString(prompt string) string
example.go 
op := input.ReadString("Select operation (+, -, *, /): ")
fmt.Println("Operation chosen:", op)

ReadStringln

Prints the prompt on its own line and reads a single whitespace-delimited token from standard input.

signature 
func ReadStringln(prompt string) string
example.go 
username := input.ReadStringln("Enter your username:")
fmt.Printf("Welcome back, %s!\n", username)

ReadBool

Prompts and reads a boolean value from standard input (accepts standard Go boolean representations like 1, t, T, TRUE, true, True, 0, f, F, FALSE, false, False).

signature 
func ReadBool(prompt string) bool
example.go 
ok := input.ReadBool("Do you like Go? (true/false): ")
if ok {
    fmt.Println("Great!")
} else {
    fmt.Println("Maybe someday")
}

ReadBoolln

Prints the question followed by a newline, then reads a boolean result from standard input.

signature 
func ReadBoolln(prompt string) bool
example.go 
proceed := input.ReadBoolln("Do you wish to proceed with the deletion?")
if proceed {
    fmt.Println("Action confirmed.")
}
