text Package

The text package provides utilities for structuring, framing, and styling console text output. It includes framed headers with automatic UTF-8 centering, horizontal dividers, and ANSI escape sequences for bold, cursive, underline, and strike styling.

import "github.com/goldchell-bra7/gos1mple/text"
📋 Functions Reference
Function Signature Category Description
Header(text, symbol, width) Layout / Framing Creates a balanced framed banner with UTF-8 rune centering
Separator(symbol, width) Layout / Divider Generates a repeated symbol horizontal dividing line
Bold(prompt) ANSI Styling Renders text in bold font style (\033[1m)
Cursive(prompt) ANSI Styling Renders text in italic/cursive style (\033[3m)
Underline(prompt) ANSI Styling Adds an underline under terminal text (\033[4m)
Strike(prompt) ANSI Styling Applies strikethrough styling to text (\033[9m)
🔍 Detailed Documentation

Header

Centers the provided text within the specified width and encloses it in horizontal borders composed of the given symbol above and below. UTF-8 rune counting (via utf8.RuneCountInString) ensures international characters and emojis are counted by visual column width rather than raw byte length.

signature 
func Header(text, symbol string, width int) string
example.go 
fmt.Println(text.Header("System Status", "=", 40))
terminal output 
========================================
             System Status              
========================================

Separator

Creates a horizontal divider string by repeating the specified symbol a given number of times. Perfect for visually dividing menus, log entries, and sections in CLI tools.

signature 
func Separator(symbol string, width int) string
example.go 
fmt.Println(text.Separator("-", 40))
fmt.Println("Section 1: Configuration loaded")
fmt.Println(text.Separator("-", 40))

Bold

Wraps the provided string with the ANSI sequence \033[1m and automatically appends \033[0m to reset styling. Ensures formatting never leaks into subsequent terminal output.

signature 
func Bold(prompt string) string
example.go 
fmt.Println(text.Bold("IMPORTANT: Operation is irreversible."))

Cursive

Wraps the string with the ANSI italic sequence \033[3m and resets formatting at the end with \033[0m. Note: Terminals without italic support will render normal text without breaking.

signature 
func Cursive(prompt string) string
example.go 
fmt.Println(text.Cursive("Tip: Press Ctrl+C to exit any time."))

Underline

Applies standard ANSI underline formatting (\033[4m) and resets formatting with \033[0m.

signature 
func Underline(prompt string) string
example.go 
fmt.Println(text.Underline("https://github.com/goldchell-bra7/gos1mple"))

Strike

Wraps the string with ANSI strikethrough escape sequences (\033[9m) and resets formatting with \033[0m. Great for depicting deprecations or completed tasks in CLI checklists.

signature 
func Strike(prompt string) string
example.go 
fmt.Println(text.Strike("[x] Old configuration format"))
fmt.Println("[ ] New v2 configuration format")
