Installation Guide

Everything you need to know to install, configure, and verify gos1mple in your Go projects.

Step 1

Prerequisites

gos1mple is built for modern Go environments and requires Go 1.18 or newer (compatible through Go 1.26+). Verify your active Go runtime:

terminal 
$ go version
# Output: go version go1.26.4 linux/amd64
Step 2

Initialize Your Go Module

If you are starting a fresh project, initialize your Go module:

terminal 
$ mkdir myapp && cd myapp
$ go mod init myapp
Step 3

Install the Library

Add gos1mple to your go.mod file using go get:

Option A: Install Latest Release (Recommended)

$ go get github.com/goldchell-bra7/gos1mple@latest

Option B: Pin Specific Version

$ go get github.com/goldchell-bra7/gos1mple@v0.3.0
Step 4

Verify Your Installation

Create a test file main.go with the following code to confirm everything works smoothly:

main.go 
package main

import (
    "fmt"

    "github.com/goldchell-bra7/gos1mple/color"
    "github.com/goldchell-bra7/gos1mple/input"
    "github.com/goldchell-bra7/gos1mple/text"
)

func main() {
    fmt.Println(text.Header("gos1mple Setup Complete", "=", 40))
    name := input.ReadString("What is your name? ")
    greeting := fmt.Sprintf("Welcome to Go, %s!", name)
    fmt.Println(color.Term(text.Bold(greeting), color.BrightGreen))
}

Run the file:

terminal 
$ go run main.go
