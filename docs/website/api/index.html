API Reference

Comprehensive documentation for the gos1mple ecosystem. The library provides three modular packages engineered to make terminal interaction fast, intuitive, and visually pleasing.

📦 Packages
📥

input

Centralized, type-safe functions for capturing console user inputs (integers, floats, strings, booleans) with inline or newline prompts.

8 Functions
📝

text

Lightweight formatting utilities for terminal text, including centered framed headers, horizontal dividers, bold, cursive, underline, and strikethrough.

6 Functions
🌈

color

ANSI color output helpers featuring the Term() function and 25 color constants spanning standard, bright, and background palette fills.

1 Function · 25 Constants

Install gos1mple

Quick Installation

Get started with gos1mple in your Go project.

1

Download latest version

$ go get github.com/goldchell-bra7/gos1mple@latest
2

Or pin to v0.3.0

$ go get github.com/goldchell-bra7/gos1mple@v0.3.0
3

Import packages

main.go 
import (
    "github.com/goldchell-bra7/gos1mple/input"
    "github.com/goldchell-bra7/gos1mple/text"
    "github.com/goldchell-bra7/gos1mple/color"
)
