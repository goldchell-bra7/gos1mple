color Package

The color package provides ANSI escape sequences for terminal text colorization. It offers the Term() helper function and 25 color constants spanning standard foregrounds, bright foregrounds, and background fills.

import "github.com/goldchell-bra7/gos1mple/color"
⚡ Core Function

Term

Wraps the provided text string with the selected ANSI color constant and automatically appends Reset (\033[0m) at the end. This prevents active color styles from bleeding into subsequent terminal output.

signature 
func Term(text, colorConst string) string
example.go 
fmt.Println(color.Term("Build succeeded!", color.BrightGreen))
fmt.Println(color.Term("Error: file not found", color.FillRed))

💡 Composition Example

Combining Colors with Text and Input

Combine color.Term, text.Bold, and input.ReadBool to craft rich, polished interactive terminal interfaces:

demo.go 
package main

import (
    "fmt"

    "github.com/goldchell-bra7/gos1mple/color"
    "github.com/goldchell-bra7/gos1mple/input"
    "github.com/goldchell-bra7/gos1mple/text"
)

func main() {
    fmt.Println(text.Header("CLI Deployment Assistant", "=", 45))
    proceed := input.ReadBool("Deploy to production? (true/false): ")

    if proceed {
        fmt.Println(color.Term(text.Bold("STATUS: DEPLOYING..."), color.BrightGreen))
    } else {
        fmt.Println(color.Term("Deployment cancelled by operator.", color.Yellow))
    }
}
